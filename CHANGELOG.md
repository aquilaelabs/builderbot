# Changelog

## Unreleased

- The Artifacts tab now shows each product's version, who may move it, and this changelog (5a7b49c)
- A repo that ships two products can version each one on its own — an extension beside an app no longer share one number (d9ae96d)
- A project with no version yet can be given one from the Artifacts tab, or ask the project's Claude session to propose one (5a7b49c)
- Every version gets a changelog beside it: sessions log what changed for you, and a bump dates the accumulated entries (a2e21cc)
- An unreleased bump can be taken back — the number returns, its changelog entries rejoin the queue, the code stays (cb5cbad)
- Model and effort for everything sent to Claude are set once on a sidebar card instead of being asked at every send (9b8c1b2)
- The version stamp in the header became an About popup — no more truncated string on a phone (3accee0)
- Sessions no longer open on a wall of yellow permission warnings (d9508b0)
- Long lists in the notebook show a page at a time, with a Show more control (7a6cf2d)
- A version bump now stages until you press Save — Revert or leaving the page discards it (7a6cf2d)
- The Claude card now says which model Claude is actually on, not just what it would switch to (b38d4db)
- Asking Claude about a version now lands in the session instead of sitting unsent in the prompt (b38d4db)
- Changing the Claude model no longer swallows the message sent right after it (42a9338)
- A project with a compose file can be built and run on the box from its Artifacts tab — Up, Down, Env and Rebuild, no GitHub minutes (b2b6055)
- The dev-instance controls find the Docker socket proxy on their own — no address to look up (fb8e28d)
- The dev instance's env editor opens on the project's own .env.example, comments and all (cf0b1ef)
- A build interrupted by a restart says so, instead of looking like a button you never pressed (f686077)
- Committing now wakes the Rebuild button and the version evidence without a refresh (f686077)
- Re-running the image build by hand no longer forces the whole image to be downloaded again — tick Rebuild every layer when that is what you want (aca730b)
- New: 'bb catchup' prints what has happened here lately — recent commits and why, what moved in the roadmap and bug tracker, the builds, and which image this box is running (8253d8a)
- The container now keeps a record of every image it has run, so 'which build was I on when I saw that?' has an answer after the fact (8253d8a)
- The dev instance's Down button now works when the app has crashed rather than been stopped, and the row says which of the two happened (181b40b)
- A project's dev instance now says what its compose file reaches for beyond the project — a host mount, privileged, extra capabilities — and asks once before starting it (b910384)
- The command lists and Sessions moved out of the sidebar and under the terminal, where the phone has always had them — seven cards on the left instead of twelve (76ecf27)
- A dev instance whose compose file uses paths only BuilderBot can see is told so on its row, rather than starting with an empty directory mounted in its place (76ecf27)
- The header has a bell: errors and messages are kept there instead of vanishing with their toast, and a session waiting to reach your phone can be approved or denied from it wherever you are on the page (395fe92)
- On a desktop the Commands and Sessions flyouts now slide open over the terminal instead of pushing it up, and the on-screen keyboard button is gone where there is a real keyboard (395fe92)
- A project's notebook opens on Memory, keeps the tab you were on while it stays open, and starts fresh at Memory once you close it (0bb10d2)
- The dev instance now reads like the rest of the Artifacts list: a docker pill, the container's own name, and whether it is running beside it (ea944dd)
